# Тест скорости интернета (консольный скрипт)

[![Tests](https://github.com/krasavitsalee/speedtest-cli/actions/workflows/tests.yml/badge.svg)](https://github.com/krasavitsalee/speedtest-cli/actions/workflows/tests.yml)

Небольшой консольный скрипт, который измеряет скорость скачивания: делает
N последовательных запросов к указанному адресу (например, к тяжёлой
картинке), дожидается полного ответа на каждый и выводит результаты.

## Требования

- Python 3.8+ (используется только стандартная библиотека, `pip install` не нужен).

## Запуск

```bash
python3 speedtest.py <URL>
```

Пример:

```bash
python3 speedtest.py https://example.com/heavy-image.jpg
```

По умолчанию делается 10 запросов. Дополнительные опции:

```bash
python3 speedtest.py <URL> -n 5 --timeout 30 --progress --output json --output-file result.json
```

Основные флаги:

- `-n, --count` — число запросов (по умолчанию 10)
- `--timeout` — таймаут на запрос, с (по умолчанию 60)
- `--chunk-size` — размер чанка при чтении, байт (по умолчанию 65536)
- `--retries` — число повторных попыток на запрос (по умолчанию 3)
- `--retry-delay` — базовая задержка между повторами, с (по умолчанию 1.0, экспоненциальный backoff)
- `--proxy` — URL прокси (http/https)
- `--header "Key: Value"` — дополнительный заголовок (можно повторять)
- `--progress` — показывать прогресс скачивания
- `--output {text,json,csv}` — формат вывода (по умолчанию text)
- `--output-file` — записать json/csv в файл

Скрипт делает N последовательных запросов, полностью считывает тело ответа
на каждом из них, затем печатает среднее время запроса, общий объём
скачанных данных и скорость скачивания. При сбое одного запроса серия
продолжается, в итоге печатается число успешных.

## Единицы измерения

- Время запроса — секунды (с).
- Объём скачанных данных — байты (и мегабайты, 1 МБ = 1 000 000 байт).
- Скорость скачивания — **мегабайты в секунду (МБ/с)**, где 1 МБ = 1 000 000 байт.
  Дополнительно выводится эквивалент в мегабитах в секунду (Мбит/с)
  (1 байт = 8 бит).

Скорость вычисляется как общий объём скачанных байт, разделённый на
суммарное время всех запросов.

## Что скачивается

Скрипт **не сохраняет файлы на диск**: данные скачиваются в память
(чанками), подсчитываются байты и время, после чего данные отбрасываются.
На диск ничего не записывается (если не указан `--output-file` для
результатов).

Что именно скачивается — зависит от переданного URL. В тестах можно
использовать сервис вроде `https://httpbin.org/bytes/1000000` (отдаёт
указанное количество случайных байт) или ссылку на реальную «тяжёлую»
картинку.
